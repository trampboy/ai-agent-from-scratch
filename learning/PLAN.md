# 小模型训练学习计划

确认日期：2026-10-05。当前阶段：P0，用户确认理解梯度累加，准备多个样本训练与未见输入检查。

本计划用于学习模型训练全过程，并逐步把自己训练的小模型接入当前 Agent。主线是自己实现微型 GPT、从随机权重预训练、监督微调和工具调用；完成后，再使用已有的 Qwen 权重做对照实验。GAIA 是后续应用与评测目标，不承诺教学模型能够全面替代当前 DeepSeek 服务。

## 已确认的条件

- 目的：掌握基本训练技能，理解代码、数据和实验结果。
- 硬件：本机会话读取为 Apple M5、32GB 统一内存；尚未进行训练速度与内存实测。
- 成本：优先本机。先用小样本测通流程，遇到明确瓶颈后再估算云训练成本。
- 教材：《从零构建大模型》为主线，《动手构建大模型》用于补充微调和部署知识。当前仅提供封面，尚未读取书籍正文。
- 项目基础：已有 my_agent 教学实现；保持 scratch_agents 参考实现不变。
- 当前环境已发现 uv、Python 3.13.7 和项目 .venv；尚未验证 PyTorch、MPS 或 MLX 的安装与可用性。
- 2026-10-08 建立独立 learning/.venv，安装 PyTorch 2.14.1、NumPy 2.5.3；CPU 自动求导与 SGD 已验证，未进行 GPU 训练实测。完整依赖版本保存在 learning/requirements.txt。

## 协作方式

每次只推进一个可验收的小任务：先说明目标和必要概念，由学习者动手实现或回答，再一起检查结果、定位错误并记录进度。优先给提示和解释；需要完整示例时再提供，避免直接代写整个学习项目。

完成任务必须有证据，例如代码、运行输出、实验记录或能独立解释的答案。阅读资料或运行成功本身不代表理解。每次验收后更新本文件的状态、问题与下一步。

后续从本文件恢复进度；不设置自动提醒或后台训练。训练代码使用独立目录与环境，具体依赖在开始代码练习时确认，避免影响当前 Agent 环境。默认不提交 Git、不下载大模型、不启动付费服务。

## P0 理解一次参数更新

状态：进行中，纯 Python 循环更新、PyTorch 单步更新与梯度清除对照实验已完成。经解释第三轮累计梯度随实际参数变化而变化，用户确认理解。独立口头解释在后续代码讨论中继续巩固，下一项为多个样本训练。

任务：完成 [第一次梯度练习](exercises/00-gradient.md)，区分前向计算、损失、梯度、反向传播和优化器更新。能解释则直接进入 PyTorch；不熟则学习 micrograd 的标量计算图和链式法则。

验收：

- [ ] 能手算一次参数更新，并解释参数增减的方向。
- [ ] 能说明反向传播和优化器分别做什么。
- [ ] 能解释为什么多个训练步之间通常需要清除梯度。
- [x] 用一个小例子将手算结果与自动求导结果比较。
- [x] 用纯 Python 实现重复参数更新，并运行检查预测值与损失的变化。

参考：《从零构建大模型》附录 A；Karpathy 的 micrograd 教学。

补充实践：[多个样本训练练习](exercises/03_batch_training.py)。一次使用四个输入与目标，用平均平方误差作为损失，训练后检查未参与训练的 x=5。目标是理解向量 Tensor、逐元素运算、平均损失以及训练和检查的区别；这是已知简单线性关系上的学习实验，不作为复杂任务泛化能力的证据。

## P4 让自己的模型调用工具
